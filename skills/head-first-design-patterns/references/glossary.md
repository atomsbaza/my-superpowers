# Glossary

| Term | Meaning in this skill |
|---|---|
| Abstraction | A stable concept or interface that hides implementation choices |
| Aggregate | A collection that can expose an iterator |
| Algorithm skeleton | The fixed sequence managed by Template Method |
| Adapter | Object that translates an existing interface into one a client expects |
| Abstract Factory | Interface for creating related product families |
| Anti-pattern | A commonly chosen but harmful solution with known failure modes |
| Composite | Tree node that contains child components and shares a component protocol |
| Concrete operation | Shared implementation supplied by a Template Method superclass |
| Concrete State | State-specific implementation of events and transitions |
| Context | Object that delegates behavior to a current State or uses a Strategy |
| Decorator | Wrapper that adds responsibilities while preserving a component interface |
| Dependency inversion | High-level and low-level policy depend on abstractions rather than directly on each other |
| External iterator | Iterator whose traversal state and advancement are controlled by the client |
| Factory Method | Creation interface whose concrete product decision is deferred to subclasses |
| Facade | Higher-level unified interface over a subsystem |
| Flyweight | Shared object that stores intrinsic state while callers supply extrinsic state |
| Force | Goal or constraint that makes a design pressure non-trivial |
| Hollywood Principle | “Don’t call us, we’ll call you”; framework code controls extension callbacks |
| Hook | Optional Template Method extension point with a default implementation |
| Intrinsic state | Flyweight data that can be shared safely |
| Iterator | Object that traverses an aggregate without exposing its representation |
| Law of Demeter | Principle of Least Knowledge; limit interactions to close collaborators |
| Leaf | Terminal object in a Composite tree |
| Macro command | Command that executes a sequence of child commands |
| Memento | Encapsulated snapshot used to restore prior state |
| Mediator | Object that centralizes communication among colleagues |
| Null Object | Safe no-op object used instead of repeated null checks |
| Observer | Dependent that receives subject updates |
| Open/Closed Principle | Open for extension, closed for modification |
| Primitive operation | Required Template Method step implemented by a subclass |
| Product family | Related objects created by an Abstract Factory |
| Prototype | Configured instance used as a template for copying |
| Proxy | Surrogate that controls access to a real subject |
| Push model | Subject sends update data to observers |
| Pull model | Observer receives notification and asks the subject for data |
| Real subject | Object that performs the work behind a Proxy |
| Receiver | Object that knows how to perform a Command’s actual action |
| Singleton | Class intended to have one instance and a global access point |
| State | Phase-specific behavior object used by a Context |
| Strategy | Encapsulated interchangeable algorithm |
| Subject | Object whose changes are observed or interface implemented by proxy and real subject |
| Template Method | Method that fixes an algorithm skeleton and defers selected steps |
| Transparency | Composite design choice that exposes child operations on all components |
| Visitor | Object that adds operations across a stable object structure |
