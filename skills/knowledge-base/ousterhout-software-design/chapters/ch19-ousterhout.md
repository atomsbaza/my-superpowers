# Chapter 19: Software Trends

## Core Idea
Ousterhout evaluates modern software trends (Object-Oriented Programming, Agile, TDD, Design Patterns) through the lens of complexity.

## Key Concepts
- **Agile Development**:
  - Critique: The emphasis on "working software over comprehensive documentation" and "sprints" heavily encourages Tactical Programming. Agile can easily lead to a mess if design isn't explicitly prioritized.
- **Test-Driven Development (TDD)**:
  - Critique: Focuses attention on getting specific tests to pass (tactical) rather than on finding the best overall design. Ousterhout argues against strict TDD, preferring "Design first, write code, then write tests".
- **Design Patterns**:
  - Praise: Great for consistency.
  - Critique: Can lead to over-engineering (applying a pattern where a simpler solution would work).

## Modern Context
While Agile and TDD have evolved, the warning remains valid: any methodology that hyper-focuses on short-term deliverables risks sacrificing the long-term architectural depth of the system.\n
