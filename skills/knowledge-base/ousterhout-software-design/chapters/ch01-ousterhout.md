# Chapter 1: Introduction

## Core Idea
The greatest limitation in writing software is our ability to understand the systems we are creating. Software design is about managing this complexity.

## Key Concepts
- **Complexity**: Anything related to the structure of a software system that makes it hard to understand and modify the system.
- **The Tactical vs Strategic approach**: Distinguishing between just getting features to work (tactical) versus building a clean design that allows future features to be added quickly (strategic).

## Mental Models
- Think of software engineering as a battle against complexity. If you do not actively fight it, it will overwhelm the system.\n
