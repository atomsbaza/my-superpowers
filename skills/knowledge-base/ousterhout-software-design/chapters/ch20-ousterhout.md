# Chapter 20: Designing for Performance

## Core Idea
Performance optimization usually increases complexity. Only optimize when necessary, and do it strategically.

## Frameworks Introduced
- **The Optimization Process**:
  1. Measure to find the actual bottleneck (do not guess).
  2. Design the optimization to minimize the complexity added to the system.
  3. Redesign the critical path to execute with fewer operations.

## Key Takeaways
1. Clean design and performance are usually compatible. Deep modules localize performance bottlenecks, making them easier to optimize without disrupting the rest of the system.\n
